# CAD panel command probe

`PATPANELVERIFY` is a diagnostic for AutoCAD 2026 and the 2025 plugin. Run only in a disposable test drawing with a matching dictionary containing `901`, after explicitly NETLOADing the candidate plugin and this probe. It opens PATPALETTE, requests PATMARK through its public panel API, and uses the real Brace/Align/Check button handlers through `Button.PerformClick` while a host prompt is active. It records actual host command events, all seven directional switches, rapid latest-request replacement, and deferral during a native LINE command. A timeout records FAIL and unexecuted cases as SKIP.

This is **L2_HOST_INTERNAL**. It verifies real host event and queue behavior but bypasses mouse/keyboard input and PATMARK list double-click. It cannot establish L3/L4 panel UI acceptance or visual geometry. Run the same first scenario against the pre-fix DLL to demonstrate a red result. Check the reported `Assembly` against the intended candidate path and calculate the candidate SHA-256 outside AutoCAD.

Interactive targets must retain a live input prompt. PATCHECK must complete and update this drawing's result with unmarked number `901`; command failure events fail the run. Only use a blank drawing: cancelling prompts must not create entities. Start each red/green run in a fresh process. Registered demand-load can load an older plugin before SCR NETLOAD; an `Assembly` mismatch invalidates the run. Preserve and restore only the product's LOADCTRLS setting when isolating a candidate, without changing CAD security settings. End the SCR immediately after the report filename; an extra blank command repeats PATPANELVERIFY and prevents the timer from testing an idle editor.

Build with `dotnet build tools/CadPanelSwitchProbe/CadPanelSwitchProbe.csproj -c Release -p:PatentMarkerAssemblyPath=<absolute-candidate-dll> --artifacts-path <temp-output>`. After NETLOAD, enter `PATPANELVERIFY` and an absolute report filename without surrounding quotes. Preserve the report and host log; do not install the probe or include it in deployment packages.
