# Word → Visio 只读标注原型 0.1.4.0（实验性）

**打开面板**：安装后完全退出并重新启动 Visio，自动出现“专利标注字典工具 · Visio”；关闭或最小化后从 Windows 任务栏或 `Alt+Tab` 恢复。未出现时按包内 README 的“怎样打开标注面板”检查 COM 加载项。

发布时上传 [2026-10-01 验证记录](test-evidence/office-release-validation-20261001.md) 中列出的最终 ZIP；该记录包含包 SHA-256、实际加载 DLL 与冷启动运行 ID。

加载项读取 Word 导出的 `.dict.json`，为已有 Visio 前景页的一维线添加编号框和终点箭头，按整份文档检查漏标。标注配对信息保存在 ShapeSheet；编号框与线不分组。字典只读，产品不会修改 Word、CAD 或外部 JSON。

本版本将 Office 专用字典模型、只读解析器、COM 扩展接口和诊断日志改为共享源码。Visio 保持独立 DLL、安装身份和宿主实现；与 CAD 共用的代码仅为编号比较器。

`verify-code.ps1` 可重现代码与隔离安装门禁：Visio 24 项代码测试、安装失败回滚与卸载哨兵检查通过。代码测试新增空选、多选、普通矩形及已有标注线的拒绝检查；故障注入证明普通矩形测试会抓住校验被移除的情况。本机 Visio 16 x64 面板操作和重开范围以验证记录为准。

2026-10-03 同一安装DLL在Visio16 x64通过原生直线和默认直角连接线的鼠标拖画/选线、静态连接点粘合、目标移动跟随、一次撤销及重做、默认/最低尺寸面板目检，以及保存后正常冷启动并从界面重开。完整范围见[鼠标与视觉验收](test-evidence/office-visual-validation-20261003.md)。官方截图仍超时，实际输入使用用户授权的备用工具。

真实旧版 Visio 宿主、复杂组、其他连接线路由、图片的其他粘合方式及Windows 7 + Visio 2010 x86仍待验。线起点移动后编号框不会自动跟随。既有2026-10-01 ZIP及其内部README保留原验收时的字节，后续补验以源码仓库记录为准。

同日的旧 VSD 格式补验也通过：本机 Visio 16 从界面转换为 VSD、原生新增标注、保存及冷重开后，全部页面与绑定字段相同，字典字节/属性不变。此结果不能外推真实旧版 Visio 宿主，见[本机补充验收](test-evidence/office-local-validation-20261003.md)。

带静态连接点的导入 PNG 另通过原生粘合、标注、图片移动跟随及独立冷重开，图像数据和字典不变。一次打开文件前的进程退出仍未确认原因；保留未完成尝试后，一次新的独立冷进程完成实际检查。该范围不包括插件图片导入、连接点创建或动态粘合，见上述补充验收。
