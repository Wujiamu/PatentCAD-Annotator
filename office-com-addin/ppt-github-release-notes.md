# Word → PowerPoint 只读标图原型 0.1.2.0（实验性）

发布时上传 [2026-10-01 验证记录](test-evidence/office-release-validation-20261001.md) 中列出的最终 ZIP；该记录包含包 SHA-256、实际加载 DLL 与冷启动运行 ID。

加载项读取 Word 已导出的 `.dict.json`，在已保存的 PowerPoint 演示文稿里把原生直线与编号组成标注组，并检查整份演示文稿的漏标。它不会回写字典，也不会修改 Word 或 CAD 文件。ZIP 内的 `README.md` 有安装、使用和卸载步骤。

本版本将 Office 专用字典模型、只读解析器、COM 扩展接口和诊断日志改为共享源码。PPT 与 Visio 保持独立 DLL、安装身份和宿主实现；与 CAD 共用的代码仅为编号比较器，统一去首尾空格和大小写比较。

代码与隔离安装门禁可由 `verify-code.ps1` 重现；PPT 7 项代码测试、安装失败回滚与卸载哨兵检查通过。本机 PowerPoint 16 x64 的面板操作和重开范围以验证记录为准；历史 0.1.1.0 的验证不能代替本包验证。

2026-10-03 同一安装DLL在PowerPoint16 x64通过四方向鼠标拖画/选线、编号及箭头目检、重复编号、整稿检查、默认/最低尺寸面板，以及保存后正常冷启动并从界面重开。实际截图及输入使用用户授权的备用工具；官方截图仍超时。完整范围见[鼠标与视觉验收](test-evidence/office-visual-validation-20261003.md)。

同日补验安装版 Word 的单 DWG 导出、多 DWG 取消与手选，再由 PPT 面板逐份读取、漏标检查、保存和独立冷重开通过。不同主名的两份 PPT 自动恢复各自相对字典关联；字典及非产品资产不变。仅验证手动导出与 DWG 文件名哨兵，范围见[本机补充验收](test-evidence/office-local-validation-20261003.md)。

Windows 7 + Office 2010 x86、其他显示比例和大型真实文稿仍未验证。本包不包含 Visio 功能、图片导入或 CAD 式幻灯片取点。既有2026-10-01 ZIP及其内部README保留原验收时的字节，后续补验以源码仓库记录为准。
