AutoCAD 2010/2011/2012 托管 DLL
==================================

编译前请将以下文件从 AutoCAD 安装目录复制到本目录：

  - acdbmgd.dll
  - acmgd.dll

默认安装路径示例：
  C:\Program Files\Autodesk\AutoCAD 2010\
  C:\Program Files (x86)\Autodesk\AutoCAD 2010\

注意：
  - 这些 DLL 不随仓库分发（Autodesk 版权）
  - 2010/2011/2012 三个版本的 DLL 接口兼容，任选其一即可
  - 内部版本号为 R18.0 (2010) / R18.1 (2011) / R18.2 (2012)
