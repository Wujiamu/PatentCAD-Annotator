# 2007 版大括号反向样式（废弃记录）

> **本文件原有视觉描述无效，已撤回。**

原配图 `docs/2007-brace-reversed.png` 与根目录 `panel-fix-verification.png` 字节完全相同，实际内容是 Word VBA 工具面板，不是 AutoCAD 大括号。旧版文字由非多模态模型依据错误图片和提示推断而成，曾错误声称“尖点固定朝右”“肩部应在尖点反侧”等，不得再作为需求、测试或排障依据。

用户于 2026-09-04 在对话中补充的真实截图显示：上下端点位于同一轴线，直干越过该轴线落到一侧，而中心尖点位于另一侧。其像素比例与源码的反向 `0.42W` 偏移吻合，已据此定性为当前共享几何 bug。

完整证据、根因、修复方案和验证结果见 [2007-brace-issue-tracker.md](2007-brace-issue-tracker.md)。
