# G23 — R-035（VSTest 结果归属）

负责：协调者。未 commit / push。

## 缺陷

`tools/run-office-tests-vstest.ps1` 用固定文件名 `results.trx`，再按「`-Recurse` 搜索 + 最新修改时间」取结果：

```powershell
$trx = Get-ChildItem -LiteralPath $results -Filter "results.trx" -Recurse |
    Sort-Object LastWriteTime -Descending | Select-Object -First 1
```

指定 `-ResultsDirectory` 时，若该目录已留有上一次的通过结果，而本次 `dotnet vstest` 退出 0 却没有产出新 TRX，包装器会读到**旧 TRX 的计数**并报 `PASS|VSTEST|…48/48`。这正是 R-030 那类「0 测试 + 退出 0」假绿灯的变体，只是这次伪装得更像真结果。

## 改法

每次运行分配唯一 TRX 文件名，只读该次约定的确切路径；找不到即失败。不做「最新时间」或「任意旧子目录」搜索，也不清空用户的结果目录。

```powershell
$runId = [guid]::NewGuid().ToString("N")
$trxName = "results-$runId.trx"
dotnet vstest $dll --logger "trx;LogFileName=$trxName" "--ResultsDirectory:$results" | Out-Host
...
$trxPath = Join-Path $results $trxName
if (-not (Test-Path -LiteralPath $trxPath -PathType Leaf)) {
    throw ("VSTest exited 0 but produced no result for this run: $trxPath " +
        "(stale results from earlier runs are not this run's evidence)")
}
```

原有的 `total/executed/passed` 三项计数校验保持不变（R-030 的修复未回退）。
