## 已否定的疑似问题

### 1. 空 catch 掩盖失败（47 处）

`cad-plugin` 生产代码有 47 处 `catch { }`，`office-com-addin` 另有 15 处。

逐个抽查后判定均非缺陷：集中在
- **探测语义**：`TryGetVisibleLabel`／`TryGetTag` 读不到就返回 false，调用方据此判定"不是产品标注"并记诊断——失败方向是跳过，不是误改。
- **清理路径**：删除 label、恢复箭头样式、关闭 stream、释放 hook。清理失败不应阻断主流程。
- **验证器**：`PatGeomVerifyCommand` 的断言辅助。

`DictPaletteControl.cs` 那处名为空 catch 的实为 `catch (Exception ex)` 带日志与状态栏更新，是 grep 的正则误报。

### 2. `RetryRenameInDrawing` 用回读身份而非记录身份

`DictPaletteControl.cs:1142` 调用两参数 `RenameSyncContext.Capture`，它用 `ReadIdentity(dictPath)` 回读磁盘。G24 明文写"禁止空身份退化为回读当前文件"。

**否定理由**：回读得到的是**当前真实磁盘身份**，`DecideOnBytes` 随后用 `context.SameSnapshotAs(pending)` 与记录身份比对。磁盘变了就不相等，判 `NeedsReconfirm` 并保留任务——这正是期望行为。若改用记录身份，反而会拿旧快照放行。禁止的是"把回读结果当作本次提交的成功证据"，此处回读只用于**漂移检测**，用途不同。

### 3. `ResolveCanonicalPath` 与 `IsCurrentContext` 失败语义相反

`IsCurrentContext` 在 `Path.GetFullPath` 抛异常时返回 `false`（拒绝），`ResolveCanonicalPath` 返回原始 `current`（放行）。

**否定理由**：能让 `GetFullPath` 抛异常的路径（`a|b`、`<>`、含 NUL、空串）在真实字典路径中不会出现——`ResolveDictPath` 用 `File.Exists` 过滤，这类路径对应的文件根本不存在。实测：`GetFullPath('a|b')` 抛 `MethodInvocationException`，但这样的文件无法被 `File.Exists` 返回 true。

**但这是一处真实存在的语义分歧**，虽然当前不可触发。若将来 `ResolveDictPath` 增加非 `File.Exists` 的路径来源，两者会分叉。已记录，未改代码——没有触发路径就改属于投机。

### 4. `ReadCanonicalSnapshot` 在解析路径与读取之间仍有窗口

`ResolveCanonicalPath` 返回路径，`ReadSnapshot` 再读。看似 G28 的同类问题。

**否定理由**：`ResolveDictPath` 只返回一个路径字符串，不涉及内容，不存在"身份来自一次读取、模型来自另一次"的错配。G28 修的是同一函数内两次**读文件**；这里是先取路径再读一次文件，只有一次读取。

### 5. VBA 的 `On Error Resume Next` 未及时恢复（5 处）

`AutoExport.bas` 有 15 处 `On Error Resume Next`、7 处 `On Error GoTo 0`。第 78、89、99、489、1066 行附近未见立即处理。

**否定理由**：这 5 处全部在清理路径（释放 `m_hook`、关闭 stream、恢复输出文件属性、释放锁）。VBA 里清理代码用 `Resume Next` 是惯用写法，且这几处都已通过 `WriteDiagnostic` 记录诊断。第 78 行那处还在返回前把错误号／源／描述写进诊断行。

### 6. 同一秒备份重名会覆盖恢复点

备份名为 `<主名>.dict.json.word-<yyyymmdd-hhnnss>.bak`，精确到秒。AGENTS.md 曾把它列为已知缺口。

**否定理由**：`AutoExport.bas` 已处理：

```vb
If fso.FileExists(bakPath) Then Err.Raise vbObjectError + 516, "AutoExport.Backup", "Backup already exists"
```

宁可失败也不覆盖已有恢复点，`failure` 回传给调用方阻止覆盖。AGENTS.md 该条已过时。
