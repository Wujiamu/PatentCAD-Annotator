# G27 — R-035（默认结果也必须能复核）

负责：协调者。未 commit / push。

## 缺陷

上一轮 G23 给包装器加了「每次运行唯一 TRX 文件名」，但默认调用（不传 `-ResultsDirectory`）时结果目录仍是 staging：

```powershell
$results = if ([string]::IsNullOrWhiteSpace($ResultsDirectory)) { $staging } else { $ResultsDirectory }
```

脚本打印 `PASS|VSTEST|…|trx=C:\…\PatentMarker-VSTest-<guid>\results-<runId>.trx`，随后 `finally` 把整个 staging 删掉。于是**返回的路径在脚本返回后就失效**——证据留存缺口。

G23 的验证一直显式传 `-ResultsDirectory`，正好绕开了这条默认路径，所以当时没暴露。

## 改法

默认结果目录移出 staging，落在 `%TEMP%\PatentMarker-VSTest-Results\<程序集名>\`；临时 DLL 承载目录照旧清理。每次唯一文件名与「只读该次确切路径」的归属校验（G23）保持不变。

```powershell
$results = if ([string]::IsNullOrWhiteSpace($ResultsDirectory)) {
    Join-Path ([IO.Path]::GetTempPath()) ("PatentMarker-VSTest-Results\" + $assemblyName)
} else { $ResultsDirectory }
```

不新增参数、依赖或测试运行器；不清空用户旧结果；仓库内不产生 `TestResults` 目录（项目原本没有该约定，`.gitignore` 也没有对应条目，所以没有引入）。
