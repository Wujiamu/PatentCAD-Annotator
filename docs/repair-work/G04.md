## G05 交接契约

- `SimpleJson.ParseObject` 接受完整 JSON 对象；空文件、错误根、顶层 null、非法转义／数字／标点、截断、尾随垃圾均抛 `FormatException`。旧 `DictLoader.Load` 已捕获异常、记录失败并返回 null；有缓存时不把失败结果替换已有模型或 Diff 基线，`ResolveRestoreCad` 在写目标前返回失败。
- `2007/2010 ConfigLoader.Load` 也调用 `ParseObject`；其已有 catch 保持不变，错误配置回退 `new PatConfig()`，正常配置及未知字段仍可读取。2013/2015 先用该共享解析器验证语法和根，再沿用 Newtonsoft 的原有模型映射与字段归一化。2025 使用 System.Text.Json 严格选项，不再接受注释或尾随逗号；空对象、合法空 entries、缺失／null 可选字段及未知字段仍沿用原来的归一化。
- 2007/2010 写字符串：完整转义 U+0000–U+001F，原先协议约定的 CRLF／单独 CR 统一为一个 LF；2013/2015/2025 继续保留原字符串的 CRLF。文件结构仍用 CRLF、UTF-8 无 BOM，保留 `"modified_by": "cad"` 字面格式。`DictLoader.Load`、`DictWriter.Write` 和 Serialize 签名均未改；G05 在协调者确认集成后基于本次版本继续添加读取身份及写入门禁，不重复建立解析通道。
- 现有 .NET Framework + Newtonsoft 的限制保留：未知字段中的 `1e400` 在 2013/2015 原版和候选均因 Newtonsoft 数值范围返回 null；共享语法校验本身接受该合法数值。相同输入在 net8 下可通过；不能用 net8 结果外推旧 CLR。本包未引入额外数值替换或改动现有字段映射。
