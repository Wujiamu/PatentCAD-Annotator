### R-016（补修，P1，G19）：名称含相同数字时，新增的 VBA 左边界检查拒绝合法条目

- 位置：`vba/Patterns.bas:202`、`tools/test-g02-parser.vbs:345`。
- 最短场景：解析“壳体X123 支架 123、”“壳体1123 支架 123、”“壳体AX123 支架 X123、”。空格保留，避免编号在前模式优先命中的歧义。
- 预期：分别得到 123／壳体X123 支架、123／壳体1123 支架、X123／壳体AX123 支架，与生产 C# 一致。
- 实际：三个 C# 对照均 PASS；实际 VBScript 完整提取均 0 命中。
- 根因与价值：InStr(1,m.Value,number) 找到名称中较早的同文数字，NumberStartOk 检查了错误位置。超长编号原反例已经被拒绝，不能撤销该修复。
- 修复边界：从未修剪名称捕获组末尾之后定位编号，覆盖直接编号和括号分支；C# Group.Index 行为保持。
- 精确选择器：`FAIL|display|repeat-after-letter|`、`FAIL|display|repeat-after-digit|`、`FAIL|display|repeat-prefixed-number|`；原始输出 `parser-vbs-full-host.txt`。

### R-034（补修，P1，G20）：备份损坏时，全局入口检查挡住合法的“采用 Word 版”

- 位置：`cad-plugin/Shared/Palette/DictPaletteControl.cs:667`、`cad-plugin/Shared/Palette/ArbitrateDialog.cs:97`。
- 最短场景：当前字典合法，最新待裁决备份为损坏文本；调用面板裁决事件。
- 预期：允许用户打开裁决并明确选择采用当前版本；恢复损坏备份被禁用／拒绝，稍后保留文件。
- 实际：事件直接返回“裁决失败: Backup dictionary cannot be parsed.”，无法选择采用当前版本；同一快照调用生产 KeepSelectedVersion 能成功。

- 修复边界：按动作分别使用 CurrentParsed/BackupParsed；保留上下文、双身份与锁检查，不自动删除备份。
- 精确选择器：`FAIL|valid-current-keep-action-not-rejected-by-bad-backup|`；原始输出 `palette-review-final.txt`。

### R-035（新增，P2，G23）：VSTest 包装器可以用旧 TRX 把本次零执行报为通过

- 位置：`tools/run-office-tests-vstest.ps1:39`、`tools/run-office-tests-vstest.ps1:43`。
- 最短场景：显式 ResultsDirectory 留有昨天 total=executed=passed=1 的 results.trx；注入本次 dotnet vstest 退出 0 但不生成新 TRX。
- 预期：本次没有生成结果，必须非零／SKIP/BLOCKED，不采纳历史计数。
- 实际：生产脚本选中旧 results.trx 并输出 PASS|VSTEST|Fixture|1/1；无旧文件时正确失败，新文件正常通过。
- 根因与价值：固定 results.trx 名称，递归选择最近文件，没有将所读文件绑定到本次运行。默认唯一临时目录不触发，但显式复用结果目录会触发。
- 修复边界：每次运行使用唯一日志名／子目录，仅读取这次约定的确切 TRX 后校验计数；保留真实 VSTest。
- 精确选择器：`FAIL|stale-no-run|`；原始输出 `vstest-review.txt`。
- 去重：R-030 的 FactRunner 零用例返回值不是本缺陷；它的修复不覆盖新增包装器读取历史结果，文件和责任包均独立。
